# Provenance

[简体中文](https://github.com/chchaoo/gpt-notebook/wiki/来源说明)

GPT Notebook is independently named and maintained by chchaoo. It incorporates code from [daogu-ai/chatgpt-viewer](https://github.com/daogu-ai/chatgpt-viewer), with extensive additions to editing, saving, search, export, navigation, multilingual UI and incremental history. The original MIT notices remain in [LICENSE](LICENSE) and [src/LICENSE](src/LICENSE). Product renaming does not erase code provenance.

The notebook icon was created for GPT Notebook. Documentation screenshots show the real application with fictional generated archives; see [screenshot sources](https://github.com/chchaoo/gpt-notebook/wiki/Screenshot-Sources).

ChatGPT and GPT identify the supported export source. This project is not affiliated with or endorsed by OpenAI.
